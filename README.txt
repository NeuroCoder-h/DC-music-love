DC MUSIC LOVE — ORIGINAL DESIGN EXPANSION

This project is based on the original DC Music Love single-page website supplied earlier.
The original homepage visual style and section layout are preserved. Additional pages reuse
the same dark-and-gold design, typography, buttons, navigation and section styling.

FILES
- index.html: original homepage with navigation updated to open the matching pages
- about.html, artists.html, services.html, network.html, contact.html: matching additional pages

PREVIEW
1. Extract the ZIP.
2. Open index.html in a browser.
3. Keep all HTML files together in the same folder.

IMPORTANT
- Artist names/photos and service descriptions are concept placeholders; confirm before publishing.
- The enquiry form is a front-end demo and does not send messages. Connect it to an approved contact service.
- Images load from Unsplash and require internet access.
- The original design has been retained; only page navigation and content organization were expanded.
